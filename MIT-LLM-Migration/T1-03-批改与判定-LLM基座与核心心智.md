## 一、概念题判定（首轮：1 过 3 半 2 未）

### C1 token —— 半过
- √ 「处理单元 ≠ 字符」方向正确，键盘联想类比挂靠有效。
- △ strawberry 数错 r 只猜「不以字母为单位」，未讲到「字母信息在 tokenize 阶段被抹掉」的机制。
- ✗ 中英方向猜反：以为真实 tokenizer 下英文更省；实际是常见英文词 ≈1 token 但中文一字常一 token，同一语义中文通常更费 token——学员自己实验（英文 56 token）与猜测打架时已察觉异常，诚实可嘉，但机制未解。
- ✗ BPE「高频片段合并」机制空白。
- 复攻点：BPE 合并机制 + 中英方向纠正。

### C2 训练与推理 —— 半过
- √ 训练/推理分离讲对（App 分发类比恰当：编译期 vs 运行期）。
- √ 推理时权重不改。
- ✗ 「聊久了越来越懂我」归因错误：学员猜「模型慢慢记住习惯」——正确归因是**产品把历史拼进上下文**（记忆在上下文不在权重，T1 M4），模型本身零学习。人设卡预期漏洞命中。
- 复攻点：把「懂」归因到上下文拼接，并能说清「换新会话一切归零」。

### C3 temperature/top-p —— 半过
- √ 随机性来自「候选中采样」，方向正确（Python 线概率存量起效）。
- √ top-p「累积概率截断」方向居然猜对，且 Q2 代码把降序/截断/重归一化全写出来了——但口述讲不出，**代码领先概念**，按密卷标准概念记 △。
- △ temperature「调候选门槛」表述错误：正确机制是作用于分布形状（T 作用在 logits：T<1 更尖、T>1 更平），学员实验数据（T=2.0 低频候选涨到 0.100）其实已经观察到现象，没提炼成机制。
- √ 工程判断（结构化低 T / 文案高 T）合理且有边界。
- 复攻点：temperature 的分布形状机制 + top-p 重归一化的口述。

### C4 上下文窗口 —— 过关
- √ 「无状态 → 全量携带 → 截断即遗忘」链条完整，HTTP 类比恰当。
- √ 类比断裂处讲得好：内存释放还能从磁盘读回，窗口截断是永久消失（T4 伏笔自己摸到了）。
- △ 遗留观察项：长对话贵慢只讲了计费，未提注意力计算随长度涨（O(n²)）——不降档，**T2 C6 点名回收**。

### C5 幻觉 —— 未过
- ✗ 归因「训练数据噪声 + 模型偷懒」——密卷点名的死记硬背典型，逐字命中。
- ✗ 对策只有「提示写严谨点 + 人工复核」，未按生成前/时/后分环节，也没接上检索接地。
- 值得记录的反差：学员 Q4 实验结论「流畅与自信不携带真值信息」已经摸到机制门口，概念却停在旧归因——**实验领先概念，复攻时用他自己的 Q4 输出当提示素材**。

### C6 随机鹦鹉 —— 未过
- ✗ 有立场但无反方最强论据、无可观察判据，诉诸「感觉它懂一点」——与密卷「诉诸意识/灵魂 = 未过」同类。
- 复攻点：把「理解」操作化成行为判据（新场景泛化/多步一致性/反事实应答），并给立场加边界条件。
