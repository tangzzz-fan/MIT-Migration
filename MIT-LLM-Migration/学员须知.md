# 学员须知（闭卷版）

> LLM 线采用「闭卷模式」：学员分支只有骨架文档 + 题干 + 空代码目录；密卷（提示梯 + 评分要点 + 参考答案）、参考代码、批改都在教练分支与 main 归档，学员侧物理不可见。防假学习靠机制，不靠自律。

## 你在这里能做什么

1. **看题干**：`T{n}-01-教练出题-<主题>.md`（共识五模型 + 争议三焦点 + 拷问题干）。
2. **盘点存量 + 自推五模型**：先写「iOS/Python 线里我已经有什么对应心智」，再自推 M1–M5，对教练版标注差异。
3. **闭卷作答**：写 `T{n}-02-学员作答-<主题>.md`——每题先写思考过程再给结论，附自评三档。
4. **代码实跑**：实现放 `代码/T{n}/`（空目录，自己写），`.venv/bin/python` 实跑，输出贴回作答稿；mock 与真 API 分开标注。
5. **卡住逐级要提示**：向教练按「弱 → 中 → 强」请求，看过的级数如实记进作答稿；禁止直接要答案。
6. **提交即交卷**：`git add -A && git commit`，等教练合并阅卷出 `T{n}-03`。
7. **费曼写回**：全销账后写 `T{n}-04-费曼草稿-<主题>.md`（含 iOS 对照小节）并 commit。

## 纪律红线（违反 = 该轮作废重跑）

- 不许从 git 历史/其他分支刻意翻密卷与参考代码——机制防的是「顺手可见」，刻意翻是自我欺骗；
- 自评必须诚实：「纯猜」不许写成「半懂」；只能复述名词讲不出机制的如实标半懂；
- 代码没跑起来 = 没验证；输出不贴回作答稿 = 视为未跑；
- 把 LLM 当确定性函数、说「模型记住了」这类心智错误，作答稿里出现要自我标注。

## 流程速记

```
闭卷作答 + 代码实跑 + 提交（交卷）
  → 教练按密卷判分（过/半过/未过，拆判分点）
  → 复攻（逐级提示）→ 写费曼稿 → 提交 → 下一轮
```
