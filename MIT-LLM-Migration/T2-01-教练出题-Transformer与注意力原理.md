# T2 教练出题集：Transformer 与注意力原理

> 本轮拆盒 T1 的 M1（next-token 预测器）：分布从哪来？答案 = Transformer 前向计算。原料 = 学员 Python 线数学存量（T2 线代/T3 概率/T4 PyTorch）+ T9 已练未闭环的 Transformer 旧稿。
> 学员人设：数学公式残存、直觉需重建；预期在「会算矩阵讲不出注意力语义、不知道为什么除 √d、位置信息从哪来」上暴露漏洞。
> 使用纪律：卡住按「弱→中→强」逐级提示（C1/C2）。提示与评分要点在密卷（仅教练分支），本文件是题干版。

## 一、共识：5 个核心心智模型

| # | 模型 | 一句话骨架 | iOS 存量锚点 |
|---|------|-----------|------------|
| M1 | embedding = 语义几何 | 离散 token 查表成向量，语义关系变成向量几何关系（相近 = 相似）；查表本身无智能，智能来自训练出的坐标 | enum 关联一张配置表：只是这次配置的是「语义坐标」 |
| M2 | 注意力 = 内容寻址的信息路由 | Q 发查询、K 当索引、V 是内容：每个位置按「与谁相关」加权吸收其他位置的信息，权重是 softmax 出来的连续注意力分配 | 像按内容匹配的动态 delegate：不是预先连线，而是每次按「相关度」现场路由 |
| M3 | 缩放/残差/归一化 = 可训练性的脚手架 | √d 缩放防 softmax 饱和、残差保住信息主干道、LayerNorm 稳住数值——没有它们深网络训不动 | 像 UI 布局的 Auto Layout 约束：不是业务逻辑，但没它整个视图塌掉 |
| M4 | 位置必须外挂注入 | 注意力本身对打乱顺序无感（置换不变），词序信息要靠位置编码显式注入 | 数组 vs 集合：信息一样，但有没有顺序是另一回事，得显式给 |
| M5 | 堆叠 = 逐层抽象 | 一层 = 一轮路由；多层把「局部共现」逐层炼成「长程语义依赖」，最后一层投回词表产出 T1 说的 next-token 分布 | 像渲染管线：每 pass 加工一层，最终出图（分布） |

学员自检要求：合上表复述 M1–M5，并把 T1 的 M1（next-token 分布）接上——「分布是哪一步算出来的」要能指出来。

## 二、争议：专家吵得最凶的 3 个焦点

**D1 注意力 O(n²) 太贵，线性注意力/状态空间模型（SSM/Mamba 类）会取代它吗？**
- 正方：长上下文场景二次成本是真瓶颈；SSM 类推理成本线性且显存友好，多个方向已逼近 Transformer 质量。
- 反方：注意力的「任意两位置直接交互」表达能力目前仍占优，近似/线性方案在检索类任务上常有隐性退化；生态与硬件优化也全押在 Transformer 上。
- 对迁移者的意义：工程选型要知道「窗口成本为什么涨」（T1 C4 的机制回收），但追架构新闻不是工程师的必修课——判据是任务上的 eval，不是论文声量。

**D2 Transformer 的成功到底靠注意力还是靠规模？**
- 一方：消融实验显示去掉注意力（MLP-Mixer 类）在足量数据下也能打，说明规模与数据才是主因。
- 另一方：同等预算下注意力仍更高效，长程依赖样本效率明显更好。
- 对迁移者的意义：理解「架构红利 vs 规模红利」的分账，直接影响你对 D1 的判断与对模型选型的预期。

**D3 位置信息怎么给最好（绝对/相对/RoPE）？**
- 绝对位置编码简单但外推差；相对位置与 RoPE（旋转编码）在长序列外推上更强，已成主流。
- 争议点：位置该「加在输入」还是「融进注意力计算」，以及外推能力是不是被高估的需求。
- 对迁移者的意义：你不需要会推导 RoPE，但要能回答「为什么模型知道词序」这个必被追问的问题（M4 的落地）。

## 三、概念拷问题（6 道，口述通道）

判定标准：能讲出「为什么」并迁移到新场景 = 过；只能复述公式 = 不过。**数学存量是入口不是终点：每个矩阵运算都要能说出「这一步在语义上干了什么」。**

### C1 embedding 是什么？为什么「词」能变成向量、还能携带语义？

问题：解释 embedding 查表的过程；回答「向量的坐标是谁定的、凭什么两个意思相近的词向量距离近」；再举一个你会怎么用 embedding 相似度的工程场景（不许只说「搜索」）。

### C2 用一句话讲清 Q/K/V 注意力在做什么？

问题：不许写公式先讲机制：Query/Key/Value 三者的分工、注意力权重怎么产生、加权求和的语义是什么。讲完再写出核心公式，并解释公式里每一项对应你话里的哪个角色。

### C3 注意力为什么要除以 √d？

问题：解释不缩放会发生什么（顺着「点积大小 → softmax 行为 → 梯度」这条链推），以及为什么缩放因子恰好是 √d 而不是 d 或常数。讲不出 softmax 饱和的后果 = 没过。

### C4 模型怎么知道词序？位置信息从哪来？

问题：证明（或解释）注意力本身对顺序无感；然后说明位置编码如何补上这个缺口；再回答：如果两个句子的词完全相同但顺序相反，没有位置编码的模型会把它们当成一样吗？有位置编码呢？

### C5 残差连接与 LayerNorm 各自解决什么问题？

问题：分别解释：① 没有残差时深层网络会发生什么（信息/梯度两个维度）；② LayerNorm 稳住了什么；③ 用一个 iOS 类比说明「主干道 + 支路加工」的结构为什么稳。

### C6 为什么注意力让「长程依赖」比循环结构更容易？代价是什么？

问题：对比 RNN「信息逐站传递」与注意力「任意两位置直连」，解释长程依赖在两者中的路径长度差异；然后说出注意力为这个便利付的账（复杂度随序列长度的量级），并接回 T1 C4「长对话为什么又贵又慢」。
