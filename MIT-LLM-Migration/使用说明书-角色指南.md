# 使用说明书：LLM 线学员/教练角色指南（worktree 版）

> 本文档说明 MIT-LLM-Migration「教练 / 学员」两个角色的内容边界与日常循环。采用 **git worktree 双工作目录**：教练分支与学员分支各自挂一个独立目录，同时存在、互不干扰，不需要切换分支。
> 内容边界（闭卷模式）：学员侧只有骨架文档 + 题干 + 空代码目录；密卷、参考代码、批改、费曼只在教练侧与 main 归档。防假学习靠「物理不可见」。

## 〇、一分钟看懂

一条学习线 = 一轮轮「拷问闭环」：**闭卷作答 → 代码实跑 → 交卷 → 教练按密卷判分 → 复攻销账 → 费曼写回**。内容拆放在两个 git 分支、两个 worktree 上：

| 工作目录 | 分支 | 归属角色 | 有什么 | 没什么 |
|---------|------|---------|--------|--------|
| `.worktrees/llm-coach` | `feat/mit-llm-study` | 教练 | 全量归档、`T{n}-01-教练密卷`（提示梯+评分要点+参考答案定位）、批改、参考代码、台账 | 学员的新作答（学员另写） |
| `.worktrees/llm-student` | `feat/mit-llm-study-student` | 学员 | 骨架文档（00–04）、题干、空 `代码/T{n}/`、`学员须知`、学员产出 | 密卷、参考代码、批改、旧费曼 |

合并方向铁律：**学员 → 教练**（交卷阅卷）；教练 → 学员只允许选择性单文件同步题干，严禁整支合并。

## 一、首次搭建（一次性）

```bash
cd /Users/apple/Developments/MIT-Migration
git worktree add .worktrees/llm-coach   feat/mit-llm-study
git worktree add .worktrees/llm-student feat/mit-llm-study-student
```

之后两个目录各自独立打开：教练目录看答案与归档，学员目录闭卷实操。**日常不要在两个目录之间复制答案内容。**

## 二、学员循环（在 `.worktrees/llm-student`）

1. **领题**：读 `T{n}-01-教练出题-<主题>.md`（只有题干：共识五模型 + 争议三焦点 + 拷问题干，无提示无答案）。
2. **盘点存量 + 自推五模型**：先写「iOS/Python 线里我已经有什么对应心智」，再自推 M1–M5，对教练版标注差异——不许先看模型表再复述。
3. **闭卷作答**：写 `T{n}-02-学员作答-<主题>.md`——每题先写思考过程再给结论，附自评三档（有把握 / 半懂半猜 / 纯猜）。
4. **代码硬验证**：实现放 `代码/T{n}/`（目录已建好，内含 `.gitkeep`），`.venv/bin/python 代码/T{n}/Q*.py` 实跑，文件头写撞墙记录，输出贴回作答稿。**没跑起来 = 没验证。** mock 结论与真 API 结论分开标注。
5. **卡住要提示（按协议）**：提示在教练密卷里，学员侧看不到——按「弱 → 中 → 强」向教练（对话中）逐级请求，**看过的级数如实记进作答稿**；禁止直接要答案。
6. **提交即交卷**：`git add -A && git commit`。
7. **费曼**：全过后在学员分支写 `T{n}-04-费曼草稿-<主题>.md`（脱稿重推五模型 + iOS 对照小节），再提交。

### 学员纪律红线（违反 = 该轮作废重跑）

- 学员分支绝无密卷与参考代码；`git log` 里刻意翻答案 = 自我欺骗，该轮重跑；
- 自评必须诚实：「纯猜」不许写成「半懂」；只能复述名词讲不出机制的，如实标半懂；
- 代码没跑通不许写「已验证」；mock 输出必须贴回作答稿。

## 三、教练循环（在 `.worktrees/llm-coach`）

1. **阅卷**：`git merge feat/mit-llm-study-student`（唯一合法合并方向）拉入学员作答。
2. **按密卷判分**：打开对应 `T{n}-01-教练密卷`，按评分要点逐题判 过关 / 半过（拆判分点）/ 未过；概念看「能否讲出机制并给 iOS 同事讲懂」，代码看实跑输出。产出 `T{n}-03-批改与判定-<主题>.md`。
3. **记台账**：把判定写进 `00-学习计划.md` 第五节台账。
4. **复攻主持**：半过/未过的题，提示梯逐级给（弱→中→强），不许越级、不许直接贴参考答案。
5. **复核费曼**：学员交费曼稿后按评分要点复核，整轮收官；下一轮出题在收官后进行。
6. **失真自查**：全题全对 = 人设失效；把 LLM 当确定性函数讲题还判过 = 心智失守；代码全靠抄参考实现也能判过 = 双通道失守。

## 四、归档与同步

- 学员分支新作答并入教练分支归档：在教练目录 `git merge feat/mit-llm-study-student`（唯一合法方向）。
- 教练侧改了题干要同步给学员：在学员目录 `git checkout feat/mit-llm-study -- "MIT-LLM-Migration/T{n}-01-教练出题-<主题>.md"` 单文件同步，随后自查：

```bash
git -c core.quotepath=false ls-tree -r --name-only HEAD | grep 密卷   # 必须为空
```

- 整线收官后：`git checkout main && git merge feat/mit-llm-study`，main 保持全量归档。
