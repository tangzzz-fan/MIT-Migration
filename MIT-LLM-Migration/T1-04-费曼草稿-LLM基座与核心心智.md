# T1-04 费曼草稿：LLM 基座与核心心智

> 全过后的脱稿重写（2026-08-19）。规则：不抄题干模型表，用自己的话重推 M1–M5，每个模型配一个我亲眼见过的现象；含 iOS 对照小节。判据：能不能给一个 iOS 同事讲懂。

## 一、脱稿重推五个模型

### M1 LLM 是一台「续写概率机」

给一段前缀，模型算出「下一个 token 是谁」的概率分布，然后从里面取一个，拼上去再算下一个——生成就是这么一圈圈转的。iOS 键盘联想词是同一个东西的玩具版：只是词表大到几十万、上下文长到几万 token、概率分布是海量语料喂出来的。
**现象对号**：同一个问题问两次答案不一样——因为取分布这一步带随机性，不是「查表查出了不同的行」。

### M2 训练和推理是两个世界

训练 = 在机房里用海量数据反复调权重，像开发编译期；推理 = 权重冻结后只做前向计算，像用户运行期。**运行时不改二进制**——所以对话中的模型不发生任何学习。产品让你觉得「它越来越懂我」，是因为产品把越来越长的历史拼进了每次请求，不是模型变了。
**现象对号**：开一个全新会话，昨天那个「懂我的」模型立刻变成陌生人——记忆在上下文里，不在模型里。

### M3 输出是采样出来的，确定性是特例

next-token 分布有很多合法续写，解码策略决定怎么取：temperature 改分布的形状（T<1 变尖更保守、T>1 变平更发散），top-p 改候选集（降序累积到 p 截断，核内重归一化再抽）。greedy/T→0 才是确定性——所以「输出不稳定」不是故障，是机制本身；要稳定就把采样关掉或收窄。
**现象对号**：我的 Q2 实验：T 从 0.5 拉到 2.0，「不好说」的频率从 0.7% 涨到 10%——分布被拍平的样子直接可见。

### M4 上下文窗口是全部记忆，而且是硬预算

模型无状态，像 HTTP：每次请求必须自带全量历史。「记得你」= 历史还装得进窗口；超窗就截断，被截掉的等于从未发生。窗口还是输入输出共用的预算，长对话越聊越贵。iOS 类比里最狠的断裂处：内存不够时数据还能从磁盘读回来，窗口截断是**永久消失**——除非你在外面另建存储（这是后面 RAG/记忆的伏笔）。
**现象对号**：我的 Q3 实验：名字消息在第 5 轮被挤出窗口，第 6 轮抽查立刻失忆——遗忘轮次可以被精确预测。

### M5 幻觉是结构的产物，不是 bug

模型的目标是「续写得最像人话」，里面没有「真」这个字，也没有内置的「我不知道」开关。知识缺失时分布照样给答案，于是编造得流畅又自信——**流畅与自信都不携带真值信息**。所以幻觉不能靠「提示它严谨」根治，只能三层设防：生成前把事实塞进上下文（检索接地）、生成时收窄采样并要求引用、生成后校验对账加人工确认。
**现象对号**：我的 Q4 mock：一行「坏数据」都没写，编造照样以 35% 的概率发生，语气和真实答案一样笃定。

## 二、iOS 对照小节（给同事讲的版本）

| LLM 概念 | iOS 里最像的 | 像在哪 | 断裂处（学习区） |
|---------|------------|--------|----------------|
| next-token 预测 | 键盘联想词 | 都是「按前缀给候选」 | 词表/上下文/规模放大万倍，且候选是概率分布不是固定列表 |
| 训练 vs 推理 | 编译期 vs 运行期 | 运行时不改产物 | 模型运行期连「用户级学习」都没有，一切记忆外挂 |
| 采样输出 | 无直接对应 | —— | iOS 函数是确定性的；LLM 的「同输入不同输出」是常态不是 bug |
| 上下文窗口 | 一次请求的内存上限 | 满了就得丢 | 丢掉的不可读回（无磁盘），除非外挂存储 |
| 幻觉 | 自动补全从不拒绝补全 | 都给「最像」的，不给「最真的」 | 补全错了无伤大雅，LLM 编造会进生产决策 |
| 为幻觉设计 | 网络层不可信输入的校验纪律 | 校验、重试、兜底三件套 | 校验对象从「格式」扩展到「事实」 |

一句话给同事：**把 LLM 当一个无状态的、输出带概率的、记性只有这一单的、说话从不打草稿的远程服务来设计系统**——你的网络层纪律（校验、重试、降级、鉴权）全都用得上，只是每一条的对象都变了。

## 三、旧心智纠正清单（学前 → 学后）

| 学前 | 学后 |
|------|------|
| 同输入应同输出，不一样就是不稳定 | 随机性内建于采样，确定性要主动去要 |
| 聊久了模型就记住我了 | 记忆 = 窗口内的历史拼接，模型零学习 |
| 幻觉 = 训练数据脏 / 模型偷懒 | 幻觉 = 流畅续写目标在知识缺失域的忠实执行 |
| 提示写「要严谨」就能治幻觉 | 只能三层设防：接地/收窄/校验 |
| token ≈ 单词 | token = 词表切分单元，BPE 高频合并，字母级信息被抹掉 |
| 「它懂我」靠感觉 | 「理解」要拆成行为判据逐案评估 |

## 四、自检：给 iOS 同事讲一遍

- M1–M5 每个都能用一个 iOS 类比开场、用一个自己跑出的实验数据收尾——讲得动。
- 被追问「temperature 到底改了什么」：答 logits 除以 T 再 softmax，分布形状变化，有 Q2 数据撑——站得住。
- 被追问「中文为什么费 token」：答词表构成与 BPE 合并机会，且承认字符级实验不能外推——站得住，且知道边界。
- 遗留诚实缺口：注意力为什么是 O(n²)、位置信息从哪来——我还没有机制，T2 的主题，不冒充。
