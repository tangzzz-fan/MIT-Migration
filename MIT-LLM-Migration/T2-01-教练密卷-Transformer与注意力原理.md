## 一、概念题：提示梯与评分要点

### C1 embedding 是什么？
- 弱提示：enum 加一张「每个 case 对应一组配置」的表——如果配置的是坐标呢？
- 中提示：坐标不是人定的，是训练「挤」出来的：预测任务逼着模型把常出现在相似语境的词放到相近位置。相似 = 语境相似。
- 强提示：embedding = 词表到向量空间的可学习查表；语义来自分布假设（词由其上下文定义），训练目标让语境相近的词向量收敛到近邻。工程场景例：语义去重、聚类、相似推荐、RAG 检索（T4 伏笔）——只说「搜索」不够，要说出「按语义距离而非字面匹配」。
- 评分要点：死记典型「embedding 就是词的向量表示」；真懂特征：讲清坐标来历（训练目标决定几何）+ 给出非搜索的工程用法。
- 参考答案：查表无智能，智能在训练出的坐标；语义关系几何化是后续一切（注意力、检索）的地基。

### C2 一句话讲清 Q/K/V
- 弱提示：图书馆借书：你带着什么问题去（Q）、书架上的标签（K）、书的内容（V）——借到哪本由什么决定？
- 中提示：Q·K 算「相关度分数」，softmax 把分数变成权重（和为 1），权重乘 V 再加权求和 = 该位置吸收到的信息。
- 强提示：机制一句话：每个位置用自己的 Q 去问所有位置的 K，按相关度（softmax(QKᵀ/√d)）加权吸收各位置的 V。公式 `Attn = softmax(QKᵀ/√d)V`：QKᵀ = 相关度矩阵，softmax = 归一成注意力分配，V = 被路由的内容。
- 评分要点：死记典型「Q 是查询 K 是键 V 是值」（只有名字无分工）；真懂特征：先机制后公式，且公式每项能对回话里的角色。
- 参考答案：注意力 = 可微的软查表/内容寻址，权重连续可学，这是它能端到端训练的关键。

### C3 为什么除以 √d
- 弱提示：维度 d 变大时，两个随机向量的点积的方差会怎么变？（Python 线 T3 概率存量）
- 中提示：点积量级 ~ O(d)，大了之后 softmax 输入差距被拉大——softmax 在大输入差下会怎样？（接近 one-hot，梯度趋零）
- 强提示：d 维独立单位方差向量的点积方差为 d，除以 √d 把方差拉回 1，防止 softmax 饱和（输出近似 one-hot、梯度消失、训练卡死）。选 √d 是因为它恰是点积标准差的量级，不是拍脑袋的常数。
- 评分要点：必须串起「点积量级 → softmax 饱和 → 梯度」整条链；只说「防止数值太大」= 半过。
- 参考答案：缩放是数值稳定性工程，服务于可训练性（M3）。

### C4 模型怎么知道词序
- 弱提示：把一句话的词打乱，注意力的 QK 点积会变吗？（想想求和与顺序有没有关系）
- 中提示：注意力是对所有位置做加权求和——求和满足交换律，所以纯注意力是置换不变的：必须另有输入携带位置。
- 强提示：无位置编码时「狗 咬 人」与「人 咬 狗」对模型完全同构（权重矩阵只是行列重排）；位置编码把位置信息加进输入向量（或融进注意力，如 RoPE），打乱后向量不同、注意力分布不同。
- 评分要点：能论证置换不变性 = 过；只说「加了位置编码」讲不清为什么必须加 = 半过。
- 参考答案：顺序是外挂信息（M4）；「加在输入」与「融进注意力」是两种流派（D3）。

### C5 残差与 LayerNorm
- 弱提示：iOS 里事件从 AppDelegate 一路传到底层视图——如果中间某一站把事件「改写后独占」，下游还拿得到原始信息吗？
- 中提示：残差 = 原始输入走主干道直达，层只在主干道上做增量修正（x + f(x)）：信息与梯度都有直通路径。LayerNorm = 把每个样本的激活拉回零均值单位方差。
- 强提示：无残差：深层复合后信息被逐层改写、梯度连乘后爆炸/消失，训练不动；残差让恒等映射成为默认解，训练从「学完整变换」降级为「学增量修正」。LayerNorm 稳住各层输入分布，配合优化器让深堆叠可行。
- 评分要点：信息 + 梯度两个维度都讲到 = 过；只讲其一 = 半过。
- 参考答案：两者都是「可训练性脚手架」（M3），不是语义组件。

### C6 长程依赖与代价
- 弱提示：RNN 里第 1 个词的信息要传到第 100 个词，要走几站？注意力要走几站？
- 中提示：RNN 路径长度 O(n)（逐站衰减），注意力任意两位置一跳直达 O(1)——但「每对位置都要算相关度」意味着计算量是多少对？
- 强提示：RNN 长程信息要穿过 n 步隐藏状态（衰减/梯度难传）；注意力一跳直达但每层要算 n² 对相关度 → 计算与显存 O(n²)。接回 T1 C4：长对话贵慢的机制原因 = 注意力平方成本 + token 计费双重叠加。
- 评分要点：路径长度对比 + O(n²) 量级 + 接回 T1 = 过；只说「注意力更强」无代价分析 = 半过。
- 参考答案：便利与成本是同一枚硬币（D1 的判据入口）。
