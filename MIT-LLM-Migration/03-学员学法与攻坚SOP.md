# 学员学法与攻坚 SOP：我会怎么学

> 视角：学员第一人称。人设见 [[01-学员人设卡.md|01-学员人设卡]]，流程与台账见 [[00-学习计划.md|学习计划]]，代码载体见 [[02-项目驱动实践路线.md|项目驱动实践路线]]。
> 一句话学法：**不背 LLM 名词，只追机制与证据**——先找 iOS 类比，再拆机制，mock 实验是可观察证据；类比断裂处就是学习区。

## 一、学习姿态（三条总纲）

1. **类比先行，断裂处深挖**：每个新概念先问「iOS/客户端里最像它的是什么」，再追问「哪里不像」——不像的地方（概率采样、无状态、上下文即记忆）才是真学习区，禁止拿类比当结论。
2. **名词必须落到机制**：token/注意力/RLHF/ReAct/Harness 每个名词都要能往下讲一层「它是怎么工作的」；只能复述定义 = 没学。
3. **一切结论要有运行证据**：采样分布、注意力矩阵、eval 通过率都要贴本机输出；「感觉模型更聪明了」不算结论。

## 二、每主题七步循环 SOP

| 步 | 动作 | 产出 | 自查红线 |
|---|------|------|---------|
| 1 | 盘点存量：该主题在 iOS/Python 线里我已经有什么对应心智 | 类比清单（像/不像两栏） | 不许跳过存量直接背名词 |
| 2 | 自推五模型，再对教练版 | 自推版 + 差异标注 | 先对答案再复述 = 无效 |
| 3 | 闭卷作答概念题，逐题自评 | 作答稿（思考过程 + 自评三档） | 自评诚实，「纯猜」不许写成「半懂」 |
| 4 | 卡住逐级要提示 | 提示使用记录（级别、是否点醒） | 跳级 = 纪律违规 |
| 5 | 代码硬验证（mock 实验 + 输出留档） | `代码/T{n}/` 跑通实现 + 输出 | 输出不贴回 = 视为未跑 |
| 6 | 台账复攻 + 观察项记账 | 台账行 + 类比断裂记录 | 未过不许前进 |
| 7 | 费曼讲回（含 iOS 对照小节） | 费曼草稿 | 被问倒 = 退回第 3 步 |

## 三、各主题我怎么学（预判 + 破法）

### T1 LLM 基座：先砸碎「确定性函数」心智

- **我会怎么学**：用 mock 采样器把「同一输入多种输出」跑出来，亲眼看到概率分布；tokenizer 实验把「字 ≠ token」变成数字。
- **预判卡点**：把 LLM 当查数据库；以为幻觉是 bug；把上下文窗口当无限内存。
- **破法**：每个错误心智都做一个「反证实验」——采样 100 次统计分布、超窗截断复现、幻觉最小复现。

### T2 Transformer：数学存量是入口，不是终点

- **我会怎么学**：Python 线的矩阵乘法/softmax/PyTorch 直接挂靠 QKV 计算；重点是讲清「注意力在做什么」而不是背公式。
- **预判卡点**：会算矩阵但讲不出注意力的「信息路由」直觉；不知道为什么除 √d。
- **破法**：用 Python 线 T9 参考代码对拍，每个矩阵运算都问「这一步在语义上干了什么」。

### T3 提示工程：从玄学到契约

- **我会怎么学**：Codable 数据契约心智直接平移——提示是「给模型的接口定义」，结构化输出是「返回值校验」。
- **预判卡点**：以为提示工程就是「措辞优化」；不知道 few-shot 的机制；校验失败只会重发。
- **破法**：建提示回归测试集，两版提示用数据对比，不接受「感觉更好」。

### T4 RAG 与记忆：先分清「检索」与「记住」

- **我会怎么学**：iOS 缓存经验挂靠「外挂知识 vs 内置权重」；重点是 embedding 语义空间与关键词匹配的本质差异。
- **预判卡点**：把 RAG 当搜索引擎；以为模型「学会了」检索进来的文档。
- **破法**：同义词改写的检索对比实验（关键词挂、语义检索活），加记忆分层实验。

### T5 Agent 循环：把「自动化脚本」升级成「决策循环」

- **我会怎么学**：状态机/delegate 心智挂靠 agent loop；重点是「谁在决策」——workflow 是代码决策，agent 是模型决策。
- **预判卡点**：把 agent 写成 if-else；循环终止条件缺失导致死循环；工具报错直接崩。
- **破法**：workflow vs agent 双实现同一个任务，量化「模型决策」带来的差异与风险。

### T6 Harness：运行时思维是主场

- **我会怎么学**：App 生命周期/权限弹窗/Instruments 全套挂靠——harness 就是 agent 的「操作系统层」。
- **预判卡点**：以为 harness 是 UI 壳；不知道上下文压缩、权限闸门、eval 是运行时职责。
- **破法**：每个 harness 组件都先问「iOS 里对应哪个系统机制」，再落到 agent 语境。

### T7 收束：用整件 harness 证明全线学会了

- **我会怎么学**：把 T1–T6 的组件拼成单一入口 CLI，用 eval 集自证；架构复盘记账「哪些组件值得、哪些是负债」。
- **预判卡点**：为了凑组件硬加功能；eval 用例太简单（全过但没区分度）。
- **破法**：eval 集必须含一个「需要拒绝危险操作」的用例；复盘用数据说话。

## 四、反模式自查清单（每次学习后过一遍）

- [ ] 我是不是先背了名词、再回头找「机制」？（名词复读 = 无效）
- [ ] 概念题过了，我是不是省掉了代码题？（C3 红线）
- [ ] 每个结论有没有本机运行输出？mock 与真 API 有没有分开标注？
- [ ] 我是不是拿 iOS 类比当了结论，没去验证断裂处？
- [ ] 我是不是把「模型记住了」挂在嘴边（无状态心智失守）？
- [ ] 台账里有没有把「半懂」写成「过关」？（C4 红线）
