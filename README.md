# MIT-DesignPattern-Migration：学员工作区（三处齐全版）

> 设计模式线采用「三处齐全」：题干、密卷、参考解法、示例批改、示例费曼在 **main / 教练侧 / 学员侧** 都可见。防假学习从「物理不可见」改为「自律」——**先闭卷作答，再对照参考，如实记录差距**。

## 你在这里做什么

1. 读 `MIT-DesignPattern-Migration/00-学习计划.md` 与 `01-学员人设卡.md`；
2. 每主题按 `T{n}-01-教练出题-<主题>.md` 闭卷作答：先盘点 Swift 存量写法，再自推五模型；写 `T{n}-02-学员作答-<主题>.md`，自评三档；
3. 代码题在 `MIT-DesignPattern-Migration/代码/T{n}/` 实现（同目录有参考解法，先自己写再对照），`swift` 实跑，输出贴回；
4. 作答完成后对照密卷与示例批改自批，差距如实记录；
5. 按示例费曼的格式写自己的 `T{n}-04-费曼草稿-<主题>.md`。

规则见 [学员须知](MIT-DesignPattern-Migration/学员须知.md) 与 [使用说明书](MIT-DesignPattern-Migration/使用说明书-角色指南.md)。

## 内容在哪

- 本目录（学员侧）：全量内容（题干 + 密卷 + 参考解法 + 示例批改/费曼 + 文档）；
- `.worktrees/dp-coach`（教练侧）与 `main`：同样全量（归档/查询点）。
