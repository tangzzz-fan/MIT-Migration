# 新 MIT 学习方向启动清单（MIT-<主题>-Migration）

> 用法：开新线时把本清单复制为线内 `00-学习计划.md` 的草稿（或保留本文件作检查单），逐项打勾。`<short>` = 简短英文标识（如 `swift`、`python`）；`<主题>` = 方向名（如 `Swift语言核心`）。

## 一、定方向（开工前必须答清）

- [ ] 主题与目标：要学到「能独立做什么」？写出验收标准。
- [ ] 学员人设：存量知识是什么？预期哪里该错？（人设卡模板取任一现有线 `01-学员人设卡.md`）
- [ ] 主题依赖链：按依赖排序，最后一个主题做收束（模板：现有线 `00-学习计划.md` 第二节主题表）。
- [ ] 项目载体：代码通道挂哪个工程 / Phase？（模板：现有线 `02-项目驱动实践路线.md`）
- [ ] 环境备忘：语言/工具链、依赖管理、验证命令写进线内 `00` 或 `学员须知`。

## 二、开教练分支与骨架

- [ ] `git checkout -b feat/mit-<short>-study main`
- [ ] 复制骨架：`00/01/02/03/04` 五份（模板取任一现有线），替换人设卡、主题表、项目载体
- [ ] 补 `使用说明书-角色指南.md`（worktree 版，模板取现有线）+ `学员须知.md`

## 三、出题即拆卷（每主题，教练分支）

- [ ] 写 `T{n}-01-教练出题-<主题>.md`：共识五模型 + 争议三焦点 + 概念题（6 道）+ 代码题（4 道，含脚手架），**题干版不含提示与评分要点**
- [ ] 写 `T{n}-01-教练密卷-<主题>.md`：弱/中/强提示 + 评分要点 + 参考答案定位（旧作答/批改/费曼/解法指针）
- [ ] `git add -A && git commit`（密卷与题干同 commit，密卷不进学员分支）

## 四、学员分支闭卷化

- [ ] `git checkout -b feat/mit-<short>-study-student feat/mit-<short>-study`
- [ ] `git rm` 全部 `T{n}-01-教练密卷-*.md`（学员分支绝无密卷）
- [ ] 建空 `代码/T{n}/` 目录（.gitkeep）
- [ ] 自查：`git -c core.quotepath=false ls-tree -r --name-only HEAD | grep 密卷` 必须为空
- [ ] `git add -A && git commit`

## 五、挂双 worktree

- [ ] `git worktree add ../MIT-Migration-<short>-coach feat/mit-<short>-study`
- [ ] `git worktree add ../MIT-Migration-<short>-student feat/mit-<short>-study-student`

## 六、跑闭环（每主题）

- [ ] 学员闭卷作答（自评三档）+ 代码实跑（输出贴回作答稿，撞墙留档）
- [ ] 卡住按「弱 → 中 → 强」要提示，**看过的级数如实记录**
- [ ] 教练按密卷评分要点判分：过关 / 半过（拆判分点）/ 未过
- [ ] 复攻销账 → 全过写费曼稿（含新旧技术对照）
- [ ] 台账如实（C1–C5）；前序遗留观察项点名回收

## 七、收官归档（可选）

- [ ] 整线闭环后：`git checkout main && git merge feat/mit-<short>-study`
- [ ] `git push origin feat/mit-<short>-study feat/mit-<short>-study-student`
- [ ] 更新 `README.md`：当前状态、分支布局、worktree 表
